§ 01 · THE 10 DESIGNS

Studies in form

01 / 10 · HOMEPAGE HERO

Editorial Bold Magazine

The hero reimagined as a magazine cover. Oversized Fraunces serif headline, three staggered PDF cards, a spinning "open source forever" sticker, and a scrolling marquee ribbon. Designed to make the homepage feel like a publication, not a SaaS landing page.

Editorial Fraunces Marquee Asymmetric grid

02 / 10 · TOOLS GRID

Geometric Brutalist Cards

31 tools as numbered, hard-edged blocks with 6px drop shadows. A featured "Merge PDF" card spans two columns. Color-coded by category, monospace numbering, and chunky category filter chips. Built for the Home page grid.

Brutalist Hard shadows Numbered system

03 / 10 · FILE UPLOAD

Playful Pastel Drop Zone

A floating 3D gradient icon, bouncy animation, four quick-pick source chips (Photos, Dropbox, Drive, Recent), and a gradient mesh background. Designed to make the very first interaction feel fun rather than utilitarian.

Playful 3D micro-interaction Multi-source
Open full
04 / 10 · PROCESSING STATE

Terminal Retro CRT

The processing screen as a phosphor-green terminal. Live step list with `[✓]` / `[●]` / `[ ]` markers, throughput/memory/compression stats, scanline overlay, and a blinking cursor. The tool that "shows its work" the way power users want.

Retro CRT effect Live stats
Open full
05 / 10 · DOWNLOAD STATE

Minimal Luxury Success

Refined serif "Your file is ready." with corner brackets framing the card. A file summary card showing original → new size with the savings in moss green. A single primary CTA + secondary save. The opposite of pop-up chaos.

Luxury Serif display Quiet UI

06 / 10 · MERGE TOOL PAGE

Swiss Design Workspace

A three-pane tool page: source list (left), page reorder canvas (center), output settings (right). Numbered masthead, dashed dividers, monospace metadata, color-coded source tags on every page. Maximum information density, zero chrome.

Swiss 3-pane layout Drag-and-drop

07 / 10 · COMPRESS TOOL PAGE

Organic Warm Earth Tones

Terracotta + moss + cream palette. Three preset cards (Light / Balanced / Maximum), a single-line file info bar with "14.8 MB → 7.1 MB" comparison, and a collapsible advanced section. Feels like cooking, not configuring.

Organic Preset-driven Soft shadows

08 / 10 · EDITOR TOOLBAR

Industrial Utilitarian

A dark steel editor with sectioned toolbars (FILE / NAVIGATE / ANNOTATE / VIEW), a multi-row status bar with X/Y/zoom/page info, glowing accent on the active tool, and a side properties panel for fine-grained control. Made for serious work.

Industrial Dark UI Multi-section

09 / 10 · ANNOTATION PANEL

Glassmorphism Comments

A two-pane review screen with a real PDF in the main view and a 24px-blur glassmorphic comment panel on the right. Aurora gradient background, numbered comment markers, quoted-text replies, tab filter chips. For review/collaboration.

Glassmorphism Blur effects Threaded comments

10 / 10 · MOBILE NATIVE iOS

Native iOS Three-Screen Flow

Three phone mockups in one frame: (1) Home with hero card + 8-tile quick-action grid + recent files list, (2) tool running with bottom-sheet progress + step list, (3) success sheet with circular percentage, file summary, and three share actions. Full iOS 18 patterns: blur nav, rounded sheets, system font stack.
